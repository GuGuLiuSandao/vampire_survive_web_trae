# 吸血鬼幸存者网页游戏

## 项目介绍

这是一款基于经典游戏《吸血鬼幸存者》(Vampire Survivors)玩法的网页游戏。玩家将控制角色在不断生成的敌人浪潮中生存，通过击杀敌人获得经验值升级，解锁和升级各种武器，最终挑战自己的生存极限。

## 核心玩法

- **自动攻击**：角色自动攻击范围内的敌人，玩家只需专注于移动
- **经验升级**：击杀敌人获得经验值，升级后可选择新武器或升级现有武器
- **多种武器**：包含鞭子、飞刀、魔法球等多种武器，每种武器都有独特特性
- **敌人浪潮**：敌人从屏幕外随机生成，难度随时间逐渐增加
- **生存挑战**：目标是生存尽可能长的时间，获得更高分数

## 技术栈

- **渲染技术**：HTML5 Canvas
- **游戏逻辑**：JavaScript (ES6+ 模块)
- **样式设计**：CSS3
- **开发工具**：Trae Solo
- **架构模式**：面向对象设计，模块化结构
- **无需外部依赖**：使用原生技术实现，无需安装额外库

## 快速开始

### 本地运行

1. 克隆或下载项目到本地
2. 使用浏览器打开 `index.html` 文件
3. 开始游戏体验

| 操作 | 按键 |
|------|------|
| 移动上 | W / ↑ |
| 移动下 | S / ↓ |

## 游戏特性

### 玩家系统
- 生命值和经验值管理
- 升级系统
- 多武器装备

### 敌人系统
- 多种敌人类型（基础、快速、强壮）
- 自动追踪AI
- 随机生成机制

### 武器系统
- **鞭子**：近战武器，高穿透，可升级增加射程和伤害
- **飞刀**：远程投射武器，快速攻击，可穿透多个敌人
- **魔法球**：范围攻击，可弹跳，造成持续伤害

### 界面系统
- 实时显示生命值、经验值、等级和分数
- 升级选择界面
- 游戏结束统计

## 开发说明

### 项目架构

游戏采用模块化设计，各功能模块相互独立，便于维护和扩展：

- **game.js**：游戏核心逻辑，包含游戏循环、状态管理和碰撞检测
- **player.js**：玩家角色类，处理移动、升级和武器管理
- **enemy.js**：敌人系统，包含敌人类和生成逻辑
- **weapon.js**：武器系统，实现各种武器的攻击机制
- **ui.js**：界面系统，处理HUD和游戏状态显示
- **utils.js**：通用工具函数，如随机数生成、碰撞检测等

### 开发工具

本项目使用 **Trae Solo** 进行开发，Trae Solo 是一款强大的AI辅助开发工具，能够快速生成代码、优化架构和提供开发建议。
